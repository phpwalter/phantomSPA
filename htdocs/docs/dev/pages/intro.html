The simplest way to build single-page applications with Markdown

Why phantomSPA?

Building documentation sites, blogs, or content-heavy SPAs shouldn't require complex build tools or heavy frameworks. phantomSPA lets you write in Markdown and get a fully functional SPA with routing, theming, and more.

No webpack. No babel. No build step. Just pure, simple JavaScript that works everywhere.

Features

📦 Zero Dependencies

Pure vanilla JavaScript with no external dependencies

📝 Markdown Powered

Write your content in Markdown, render as beautiful HTML

⚡ Lightning Fast

Minimal overhead, maximum performance

🔀 Simple Routing

File-based routing with zero configuration

🧩 Plugin System

Extend functionality with a simple plugin API

🔎 SEO Friendly

Server-side rendering support out of the box
