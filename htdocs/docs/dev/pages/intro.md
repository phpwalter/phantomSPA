*The simplest way to build single-page applications with Markdown.*


## Why phantomSPA?

> Building documentation sites, blogs, or content-heavy SPAs shouldn’t require complex build tools or heavy frameworks. phantomSPA lets you write in Markdown and get a fully functional SPA with routing, theming, and more.
>
> 
> **No webpack. No babel. No heavy build step.** Just lean JavaScript that works everywhere.


## Features
<!-- as:panels -->
- **📦 Zero Dependencies** — Pure vanilla JavaScript with no external dependencies
- **📝 Markdown Powered** — Write your content in Markdown; it renders as clean, semantic HTML
- **⚡ Lightning Fast** — Minimal overhead, maximum performance
- **🔀 Simple Routing** — File-based routes from a single "nav.json" file
- **🧩 Plugin System** — Extend functionality with a simple hook API
- **🔎 SEO Friendly** — Supports pre-rendering/SSR so crawlers see full content
