✅ Server-Side Rendering

Pre-render pages to static HTML for faster first paint and improved SEO. Generate your fragments at build time and serve them via contentRoot.

Strategy

  1. Read all Markdown files (or HTML sources).
  2. Transform to HTML using your parser or pipeline.
  3. Emit to the fragment folder used by contentRoot (dev: /docs/dev/pages/, prod: /pages/).
  4. Ensure each route in nav.json points to the emitted fragment.

Pseudo build script

// build-ssr.mjs (example) import { readFile, writeFile, mkdir } from 'node:fs/promises'; import { globby } from 'globby'; import { marked } from 'marked'; const src = 'content/**/*.md'; const out = 'htdocs/pages'; // prod output (dev: htdocs/docs/dev/pages) await mkdir(out, { recursive: true }); for (const file of await globby(src)) { const md = await readFile(file, 'utf8'); const html = marked.parse(md); const rel = file.replace(/^content\//,'').replace(/\.md$/,'.html'); await writeFile(`${out}/${rel}`, wrap(html), 'utf8'); } function wrap(body){ return `<section class="doc-page">${body}</section>`; }

Tip: keep the same file names in nav.json; switch only contentRoot between dev and prod.

✅ Custom Themes

Create a theme by defining CSS custom properties and toggling a root class or data-theme attribute.

Theme tokens

/* tokens.css */
:root{
  --bg:#0b1220; --fg:#c7d0de; --card:#101a2a; --line:#1e2a3f; --accent:#8fb0ff;
}
:root[data-theme="light"]{
  --bg:#ffffff; --fg:#23303f; --card:#f6f8fb; --line:#e5e9f1; --accent:#335cff;
}

Applying tokens

/* app.css */
body{ background:var(--bg); color:var(--fg); }
.card{ background:var(--card); border:1px solid var(--line); border-radius:12px; }
a{ color:var(--accent); }

Runtime toggle (tiny helper)

// theme.js
export function setTheme(name){ document.documentElement.setAttribute('data-theme', name); }
// usage: setTheme('light') or setTheme('dark')

Persist with localStorage if desired and initialize on page load.

Other Ideas

  • Link Preloading: add data-preload to important links; the router prefetches fragments on hover.
  • Partial Hydration: keep pages static; attach small, isolated JS widgets where needed.
  • Search Index: generate a JSON index at build time for client-side search.
