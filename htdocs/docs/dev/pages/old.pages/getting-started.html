Getting Started

Installation

Install MarkdownSPA via npm, yarn, or use it directly from a CDN.


npm install markdown-spa
# or
yarn add markdown-spa
# or use CDN
<script src="https://unpkg.com/markdown-spa/dist/markdown-spa.min.js"></script>

Basic Setup

Create a simple MarkdownSPA application with just a few lines of code.


// main.js
import MarkdownSPA from 'markdown-spa';

const app = new MarkdownSPA({
  root: '#app',
  pages: './pages',
  theme: 'auto',
  plugins: []
});

app.init();

Project Structure

MarkdownSPA uses a simple file-based routing system. Your project structure might look like this:


project/
├─ index.html
├─ main.js
├─ pages/
│  ├─ index.md
│  ├─ about.md
│  └─ docs/
│     ├─ getting-started.md
│     └─ api.md
└─ public/
   └─ styles.css

Writing Content

Write your content in Markdown files. MarkdownSPA will automatically convert them to HTML and handle routing.


# Welcome to My Site

This is written in **Markdown** and rendered as HTML.

## Features
- Simple routing
- Markdown support
- Zero configuration

[learn more](/docs/getting-started)
💡

Pro Tip

You can use HTML directly in your Markdown files for more complex layouts. MarkdownSPA will render both Markdown and HTML seamlessly.
