Size Variants

Each icon is available in three sizes. Use the appropriate size class alongside the base .file-icon class:

Small (16px) - .file-icon-sm

Ideal for inline text, file lists, and compact UIs.

Medium (32px) - .file-icon-md

Default size, good for file browsers and cards.

Large (64px) - .file-icon-lg

For featured displays, hero sections, and large previews.

Usage

Basic Usage

Combine three classes: base class + size class + icon type class:

<span class="file-icon file-icon-md file-icon-pdf"></span>

Result:

Class Structure

Class Purpose Required
.file-icon Base class - sets up sprite, sizing, transitions ✅ Yes
.file-icon-sm/md/lg Size variant - 16px, 32px, or 64px Optional (defaults to md)
.file-icon-{type} Icon type - sets grid position ✅ Yes

Handling Unknown File Types

The generic icon (grid position row 0, column 1) serves as a fallback for unknown or unsupported file types. Use it for files like .yaml, .toml, .lock, .env, or any extension without a dedicated icon.

Direct usage:

<!-- Explicitly use the generic icon -->
<span class="file-icon file-icon-md file-icon-generic"></span>

Result:

Automatic fallback pattern: Set the generic icon position as the default in the base class. Each icon type class then overrides these values:

/* Base class defaults to generic icon */
.file-icon {
    --icon-row: 0;
    --icon-col: 1;  /* generic icon position */
    /* ...other styles... */
}

/* Each type class overrides the position */
.file-icon-folder { --icon-row: 0; --icon-col: 0; }
.file-icon-pdf    { --icon-row: 2; --icon-col: 2; }
/* etc. */

This approach is:

  • Simple – No complex selectors needed
  • Scalable – New icons just add their own position
  • Maintainable – The default is set once in the base class

Practical example: Files without dedicated icons automatically get the generic icon:

CSS Architecture

The system uses CSS custom properties for dynamic positioning:

/* Base class sets up the calculation */
.file-icon {
    --file-icon-size: var(--file-icon-size-md);
    background-position:
        calc((var(--icon-col, 0) * -1) * var(--file-icon-size))
        calc((var(--icon-row, 0) * -1) * var(--file-icon-size));
}

/* Icon classes just set the grid position */
.file-icon-pdf { --icon-row: 2; --icon-col: 2; }

/* Size classes just change the size variable */
.file-icon-lg { --file-icon-size: var(--file-icon-size-lg); }

Extending the Icon System

Adding a New File Type

To add a new icon to the system:

  1. Add the icon to the sprite sheet - Place it in an empty grid cell or expand the grid
  2. Update the CSS - Add a new class with the grid position:
/* Example: Adding a YAML icon at position (0, 1) - using generic slot */
.file-icon-yaml { --icon-row: 0; --icon-col: 1; }

/* Example: Adding to a new row 4 */
.file-icon-rust { --icon-row: 4; --icon-col: 0; }
.file-icon-go   { --icon-row: 4; --icon-col: 1; }

If expanding the grid, update the sprite configuration:

:root {
    --file-sprite-cols: 7;  /* Update if adding columns */
    --file-sprite-rows: 5;  /* Update if adding rows */
}

Creating Aliases

Map multiple extensions to the same icon:

/* JavaScript variants */
.file-icon-mjs  { --icon-row: 3; --icon-col: 2; }
.file-icon-cjs  { --icon-row: 3; --icon-col: 2; }
.file-icon-jsx  { --icon-row: 3; --icon-col: 2; }

/* Document variants */
.file-icon-docx { --icon-row: 2; --icon-col: 3; }
.file-icon-xlsx { --icon-row: 2; --icon-col: 4; }
.file-icon-pptx { --icon-row: 2; --icon-col: 5; }

Prism Treeview Integration

For use with the Prism treeview plugin, add mappings in prism-syntax-highlighter.css:

/* Map file extension to icon */
pre[data-treeview-icons="custom"] .entry-name.ext-yaml:before {
    --icon-row: 0;
    --icon-col: 1;
}

File Size ~15KB PNG ~5-10KB WOFF2

Accessibility ✅ Decorative by default ⚠️ Needs aria-hidden
