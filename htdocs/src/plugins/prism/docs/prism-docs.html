🎨 Prism.js Syntax Highlighter

Beautiful, lightweight syntax highlighting for your code blocks that brings your documentation to life. Prism.js integrates seamlessly with PhantomSPA to provide config-driven, per-block customization using intuitive HTML comment directives. With support for over 9 programming languages, customizable themes, and powerful plugins like line numbers, line highlighting, and brace matching, you can create professional-quality code examples that are both visually appealing and highly functional. The modular architecture ensures fast load times while the drop-in system allows for easy extensibility without modifying core files.

Key Features

🎨

Syntax Highlighting

Beautiful code coloring for 9+ programming languages using the Tomorrow Night theme. Each language has carefully crafted token colors that enhance readability while maintaining visual consistency across your documentation. The highlighting engine automatically detects language-specific syntax patterns including keywords, strings, comments, and operators.

🔢

Line Numbers

Optional line numbering makes it easy to reference specific lines in discussions, code reviews, or tutorials. Line numbers are styled to be unobtrusive yet clearly visible, with proper alignment for code blocks of any length. Enable them per-block using the simple directive syntax for maximum flexibility.

✨

Line Highlighting

Draw attention to specific lines with customizable highlighting that uses a subtle background color to emphasize important code sections. Perfect for tutorials where you need to guide readers through step-by-step changes, or for documentation that explains key implementation details. Supports individual lines, ranges, and multiple selections.

📋

Copy Button

One-click code copying via the custom headers system that appears automatically on every code block. Users can instantly copy code to their clipboard without manually selecting text, improving the developer experience. The button provides visual feedback on successful copy by displaying a green checkmark icon for 2 seconds before reverting to the copy icon.

📥

Download Menu

Download code snippets as properly formatted files with correct extensions based on the detected language. The three-dot menu provides options to save code locally, making it easy for users to grab examples and use them in their own projects. File names are automatically generated from code block titles when available.

🌳

Treeview

Visualize file and folder structures with the treeview plugin that renders directory hierarchies with proper indentation and tree lines. Supports three icon modes: no icons for minimal display, native Prism icons, or custom PhantomSPA sprite icons for a polished look. Perfect for documenting project structures and file organization.

Best Practices

Recommendations for using Prism.js effectively in your documentation. Following these guidelines will help you create code examples that are both visually appealing and highly functional. Well-structured code blocks improve readability, make it easier for readers to follow along with tutorials, and ensure your documentation maintains a professional, consistent appearance across all pages.

✅

Use Line Numbers

Add line numbers for code blocks longer than 5 lines to make referencing easier. Line numbers are essential when discussing specific parts of code in tutorials, code reviews, or technical documentation. They allow readers to quickly locate the exact line being discussed and make it simple to reference code in comments or discussions.

✅

Highlight Key Lines

Use line highlighting to draw attention to important code sections. When explaining complex code or walking through step-by-step changes, highlighted lines help readers focus on what matters most. This is particularly useful in tutorials where you want to show additions, modifications, or critical implementation details without overwhelming the reader.

✅

Specify Language

Always specify the language class for proper syntax highlighting. Without a language specification, Prism cannot apply the correct token colors and patterns, resulting in plain, unformatted text. Proper language tags also enable language-specific icons in headers and ensure the correct file extension is used when readers download code snippets.

⚠️

Avoid Overloading

Don't enable all features at once; use only what's necessary. Combining too many plugins can create visual clutter and distract from the code itself. Choose features that genuinely enhance understanding—for example, use line numbers for long blocks but skip them for short one-liners, and reserve line highlighting for truly important sections rather than highlighting everything.

Available Plugins

Prism plugins extend syntax highlighting with additional features like line numbers, brace matching, command-line prompts, and file structure visualization. Each plugin is designed to enhance specific aspects of code presentation, from improving readability with line numbers to providing interactive features like brace matching on hover. Enable plugins per code block using HTML comment directives placed immediately before the <pre><code> block—this gives you fine-grained control over which features appear on each code example. Plugins can be combined freely, allowing you to create the perfect presentation for each code snippet. The directive system is processed at render time, so changes take effect immediately without requiring any build steps or configuration changes.

Basic Syntax
<!-- prism: [plugin] [flags] -->

Combine multiple plugins by separating them with spaces: <!-- prism: line-numbers match-braces -->

Plugin Description Example
line-numbers Show line numbers in gutter <!-- prism: line-numbers -->
highlight Highlight specific lines <!-- prism: highlight=2,4-6 -->
match-braces Highlight matching braces <!-- prism: match-braces -->
match-braces -R Rainbow colorization for nested braces <!-- prism: match-braces -R -->
command-line Show command prompts <!-- prism: command-line -->
treeview File structure (no icons) <!-- prism: treeview -->
treeview -N Treeview with native Prism icons <!-- prism: treeview -N -->
treeview -C Treeview with custom PhantomSPA icons <!-- prism: treeview -C -->

Deprecated Plugins

⚠️ Auto-filtered Plugins

The following plugins conflict with PhantomSPA's custom-headers drop-in module architecture, which provides enhanced code block headers with language labels, copy buttons, and download menus. These directives are automatically stripped from your code and replaced by the custom-headers functionality:

Deprecated Plugin Replacement
show-language Custom headers (language label on left)
toolbar Custom headers (integrated toolbar)
copy-to-clipboard Custom headers (copy icon button)
download-button Custom headers (three-dot dropdown menu)

If you include these directives in your code, they will be silently removed and a console warning will be logged during development.

Example: Line Numbers

⬆️

Add line numbers to make code easier to reference.

Directive
<!-- prism: line-numbers -->
// PhantomSPA Configuration
const config = {
    name: 'PhantomSPA',
    version: '1.0.0',
    features: {
        routing: true,
        plugins: true,
        markdown: true
    }
};

export default config;

Example: Line Highlighting

⬆️

Highlight specific lines to draw attention to important code.

Directive
<!-- prism: line-numbers highlight=3,5-7 -->
// User authentication module
function authenticate(user, password) {
    const hash = hashPassword(password);  // Line 3 highlighted

    if (user.passwordHash === hash) {     // Lines 5-7 highlighted
        return createSession(user);
    }

    throw new AuthError('Invalid credentials');
}

Example: Match Braces

⬆️

Highlight matching braces, brackets, and parentheses on hover.

Basic Match Braces

Directive
<!-- prism: match-braces -->
const data = {
    users: [
        { name: 'Alice', roles: ['admin', 'user'] },
        { name: 'Bob', roles: ['user'] }
    ],
    settings: {
        theme: 'dark',
        notifications: { email: true, push: false }
    }
};

Rainbow Braces (-R flag)

Directive
<!-- prism: match-braces -R -->
function deepNested() {
    return {
        level1: {
            level2: {
                level3: {
                    level4: ['a', 'b', 'c']
                }
            }
        }
    };
}
