📖 1. Introduction

What is Prism.js and how it integrates with PhantomSPA (pSPA)

What is Prism.js?

Prism.js is a lightweight, extensible syntax highlighter built with modern web standards in mind. It's used by websites like Mozilla, Stripe, and Smashing Magazine to display beautiful, readable code examples.

PhantomSPA Integration

PhantomSPA (pSPA) integrates Prism.js through a custom plugin system that provides:

  • Config-driven architecture - All settings defined in prism-config.json
  • HTML comment directives - Per-block configuration via <!-- prism: ... -->
  • Drop-in extensibility - Add features without modifying core files
  • Custom icon sprites - Language and file type icons for visual enhancement
  • SPA-aware highlighting - Automatic re-highlighting on route changes

⚠️ Important: Custom Headers vs Prism CDN Toolbar Plugins

PhantomSPA uses its own custom-headers drop-in module that automatically adds headers to all code blocks with:

  • Language icon + label (top-left)
  • Copy button (top-right)
  • Download dropdown menu (top-right)

The following directives are deprecated and automatically filtered out:

  • show-language - Replaced by custom headers (language label)
  • toolbar - Replaced by custom headers
  • copy-to-clipboard - Replaced by custom headers (copy button)
  • download-button - Replaced by custom headers (download menu)

If you accidentally use these directives (e.g., <!-- prism: show-language line-numbers -->), they will be automatically stripped out and a warning will be logged to the browser console. The remaining valid directives will still be applied normally.

Match Braces Plugin ← Config
Click on any brace, bracket, or parenthesis to highlight its matching pair
<!-- prism: match-braces -->

// Click on any brace to see its matching pair highlighted
const config = {
    app: {
        name: "PhantomSPA",
        version: "1.0.0",
        features: ["routing", "plugins", "markdown"]
    },
    plugins: [
        { name: "prism", enabled: true },
        { name: "nav-tree", enabled: true }
    ]
};

function processData(items) {
    return items.map((item) => {
        if (item.enabled) {
            return { ...item, status: "active" };
        }
        return item;
    }).filter((item) => item.status === "active");
}
Rainbow Braces (match-braces -R) ← Config
Nested braces/brackets/parentheses are colorized by depth level for visual clarity
<!-- prism: match-braces -R -->

// Rainbow braces colorize each nesting level differently
const deeplyNested = {
    level1: {
        level2: {
            level3: {
                level4: {
                    level5: ["deeply", "nested", "array"]
                }
            }
        }
    }
};

// Complex nested structure with mixed brackets
function createProcessor(options) {
    return {
        handlers: [
            (data) => {
                return data.map((item) => {
                    if (item.children) {
                        return {
                            ...item,
                            children: item.children.filter((child) => {
                                return child.active && (child.type === "node" || child.type === "leaf");
                            })
                        };
                    }
                    return item;
                });
            }
        ],
        config: {
            nested: {
                settings: {
                    values: [1, [2, [3, [4, [5]]]]]
                }
            }
        }
    };
}

⚙️ 8. Per-Block Configuration

Configure Prism features on a per-code-block basis using HTML comment directives. ← Back to config

Directive Syntax

Place an HTML comment immediately above a code block:

<!-- prism: option1 option2=value -->
Available Directive Options
Option Description Example
line-numbers Show line numbers in gutter line-numbers
highlight Highlight specific lines highlight=2,4-6
command-line Show command prompts command-line
treeview Display file structure (no icons) treeview
treeview -N Treeview with native Prism icons treeview -N
treeview -C Treeview with custom PhantomSPA icons treeview -C
copy-to-clipboard Add copy button (requires toolbar) copy-to-clipboard
download-button Add download button (requires toolbar) download-button
show-language Display language label (requires toolbar) show-language
toolbar Enable toolbar (required for some plugins) toolbar
Combined Directives Example ← Config

Multiple options can be combined in a single directive:

<!-- prism: line-numbers highlight=3,5-7 copy-to-clipboard show-language -->

// PhantomSPA Application Configuration
const app = {
  name: 'PhantomSPA',
  version: '1.0.0',
  features: {
    routing: true,
    plugins: true,
    markdown: true
  },
  init: function() {
    console.log('PhantomSPA initialized');
  }
};

// Initialize the application
app.init();
