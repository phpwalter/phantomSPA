class DataProcessor:
    def __init__(self, name):
        self.name = name

    @property
    def display_name(self):
        return f"Processor: {self.name}"

    def process(self, data):
        """Process data and return results."""
        return [x * 2 for x in data]

processor = DataProcessor("Main")
print(processor.display_name)

TypeScript Interface and generic types 

interface User {
    id: number;
    name: string;
    email: string;
}

class UserService<T extends User> {
    private users: T[] = [];

    addUser(user: T): void {
        this.users.push(user);
    }

    getUser(id: number): T | undefined {
        return this.users.find(u => u.id === id);
    }
}

JSX React component with hooks 

import React, { useState, useEffect } from 'react';

export function Counter() {
    const [count, setCount] = useState(0);

    useEffect(() => {
        document.title = `Count: ${count}`;
    }, [count]);

    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(count + 1)}>
                Increment
            </button>
        </div>
    );
}

⚙️ Per-Block Configuration

Configure Prism features on a per-code-block basis using HTML comment directives:

Directive Syntax

Place an HTML comment immediately above a code block:

<!-- prism: option1 option2=value -->
Available Directive Options
Option Description Example
line-numbers Show line numbers in gutter line-numbers
highlight Highlight specific lines highlight=2,4-6
command-line Show command prompts command-line
treeview Display file structure (no icons) treeview
treeview -N Treeview with native Prism icons treeview -N
treeview -C Treeview with custom PhantomSPA icons treeview -C
copy-to-clipboard Add copy button (requires toolbar) copy-to-clipboard
download-button Add download button (requires toolbar) download-button
show-language Display language label (requires toolbar) show-language
toolbar Enable toolbar (required for some plugins) toolbar
Combined Directives Example

Multiple options can be combined in a single directive:

<!-- prism: line-numbers highlight=3,5-7 copy-to-clipboard show-language -->

// PhantomSPA Application Configuration
const app = {
  name: 'PhantomSPA',
  version: '1.0.0',
  features: {
    routing: true,
    plugins: true,
    markdown: true
  },
  init: function() {
    console.log('PhantomSPA initialized');
  }
};

// Initialize the application
app.init();

✨ Best Practices

Recommendations for using Prism.js effectively:

✅ Use Line Numbers
Add line numbers for code blocks longer than 5 lines to make referencing easier
✅ Highlight Key Lines
Use line highlighting to draw attention to important code sections
✅ Show Language Label
Enable language labels to help readers identify the code type
✅ Enable Copy Button
Allow users to easily copy code examples for testing
⚠️ Avoid Overloading
Don't enable all features at once; use only what's necessary
⚠️ Test Rendering
Always test code blocks in the target environment
