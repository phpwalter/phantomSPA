Overview

The Vendor Icons sprite system provides 111 technology and vendor logos as a single PNG sprite with CSS-based positioning. This approach offers:

  • Single HTTP request – All icons load in one image file
  • Three size variants – 16px (small), 32px (medium), 64px (large)
  • CSS custom properties – Easy theming and dynamic sizing
  • Grid-based positioning – Simple row/column coordinates

Quick example:

<span class="vendor-icon vendor-icon-md vendor-icon-github"></span>
<span class="vendor-icon vendor-icon-lg vendor-icon-react"></span>

Small (16px) .vendor-icon-sm
Medium (32px) .vendor-icon-md
Large (64px) .vendor-icon-lg

Usage

Basic Usage

Combine three classes: base class, size class, and icon type class:

<!-- Basic usage -->
<span class="vendor-icon vendor-icon-md vendor-icon-github"></span>

<!-- Different sizes -->
<span class="vendor-icon vendor-icon-sm vendor-icon-react"></span>
<span class="vendor-icon vendor-icon-lg vendor-icon-nodejs"></span>

Class Structure

Class Purpose
.vendor-icon Base class (required)
.vendor-icon-sm/md/lg Size variant
.vendor-icon-{name} Icon type (e.g., github, react)

Handling Unknown Vendors

The base .vendor-icon class defaults to the Linux icon (row 0, col 0). Each vendor class overrides the position:

/* Base class defaults to linux icon */
.vendor-icon {
    --icon-row: 0;
    --icon-col: 0;  /* linux icon position */
}

/* Each vendor class overrides the position */
.vendor-icon-github { --icon-row: 3; --icon-col: 7; }
.vendor-icon-react  { --icon-row: 7; --icon-col: 7; }

Sprite Grid Layout

The sprite is organized as an 11×11 grid (352×352 pixels at 32px per icon):

Grid Reference

/* Grid positioning formula */
background-position:
    calc((var(--icon-col) * -1) * var(--vendor-icon-size))
    calc((var(--icon-row) * -1) * var(--vendor-icon-size));

/* Example: GitHub is at row 3, column 7 */
.vendor-icon-github { --icon-row: 3; --icon-col: 7; }

Extending the System

Adding New Vendor Icons

To add a new vendor icon to the sprite:

  1. Add the icon to the sprite image at the next available position
  2. Create a new CSS class with the grid coordinates:
/* New vendor at row 10, column 2 */
.vendor-icon-newvendor {
    --icon-row: 10;
    --icon-col: 2;
}

Creating Aliases

Create aliases for alternative names:

/* Alias for nodejs */
.vendor-icon-node { --icon-row: 4; --icon-col: 10; }

/* Alias for postgresql */
.vendor-icon-postgres { --icon-row: 7; --icon-col: 4; }

CSS Custom Properties

The system uses these CSS custom properties:

:root {
    --vendor-icon-png: url('./vendor-icons.png');
    --vendor-icon-size-sm: 16px;
    --vendor-icon-size-md: 32px;
    --vendor-icon-size-lg: 64px;
    --vendor-sprite-cols: 11;
    --vendor-sprite-rows: 11;
}
